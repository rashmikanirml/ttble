# Frontend Feature Layout

Each component is isolated in a feature folder:

- `components/` reusable UI blocks for the feature
- `pages/` route-level screens
- `api/` backend integration calls
- `types/` TypeScript models

Features:

- `user-role-management`
- `exam-timetable-auto-generation`
- `exam-hall-resource-management`
- `staff-allocation-repeat-prorata`
